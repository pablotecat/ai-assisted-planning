# Historias de usuario

Trata una historia como punto de partida de una conversación sobre un resultado para un usuario o comprador, confirmando qué significa el éxito. Aplica las ramas pertinentes:

1. Identifica lo aportado: beneficiario y objetivo, procedencia, horizonte de planificación, trabajo relacionado, restricciones conocidas y comprobaciones acordadas. Señala carencias materiales y distingue hechos de inferencias. Si la clasificación es incierta, usa [principios](references/principles.md). **Fin:** cada hecho necesario para decidir está aportado o expresamente desconocido.
2. Para convertir una idea en candidata, usa [redacción](references/drafting.md). Para diagnosticar o reformular un elemento existente, usa [revisión](references/reviewing.md). Usa ambas si la revisión requiere una reescritura fundamentada. **Fin:** cada resultado solicitado tiene candidato, hallazgo o motivo de aplazamiento.
3. Para significado de terminado, excepciones, cualidades vagas o reglas transversales, usa [confirmación](references/confirmation.md). Para estimaciones, prioridades, límites de iteración, interfaces externas o coordinación, usa [contexto](references/context.md). Lee solo las secciones pertinentes. **Fin:** cada rama relevante está aplicada y cada decisión abierta tiene responsable.
4. Devuelve la propuesta o dictamen, su valor y la razón de cada cambio material. Separa acuerdos de sugerencias y señala preguntas materiales y quién puede resolverlas. Si actor y resultado carecen de fundamento, devuelve una propuesta pendiente con preguntas concretas. Al redactar o revisar un entregable de historia, carga [plantillas-entregables](../plantillas-entregables/SKILL.md) y aplica [Historia](../plantillas-entregables/references/historia.md), también para división, trazabilidad e incidencias. Esta skill conserva los criterios de contenido; aquella define el formato. **Cierre:** cada recomendación está fundamentada o marcada provisional, se distinguen criterios propuestos de acordados, y el solicitante sabe qué adoptar y qué debe decidir una persona.
