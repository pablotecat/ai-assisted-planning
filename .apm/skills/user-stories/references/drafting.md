# Redactar desde una idea

1. Traza la petición a la evidencia: quién usa o compra el producto, en qué situación, qué resultado busca y por qué. Distingue evidencia directa de usuarios, testimonios de compradores o representantes e inferencias propias. **Fin:** cada afirmación sustantiva tiene una base aportada o un desconocido explícito.
2. Si el rol o el objetivo son ambiguos, formula preguntas abiertas y concretas sobre el flujo actual y el resultado deseado. Usa un rol específico cuando se conozca; distingue usuarios que operan el producto de compradores. Trata los testimonios de representantes como pistas útiles y busca feedback de usuarios cuando sea viable; remite los objetivos en conflicto a la persona responsable del valor del producto. **Fin:** el objetivo tiene una base creíble o están identificados la decisión pendiente y su responsable.
3. Expresa una candidata breve por cada resultado significativo distinto. Usa una plantilla o cláusula de valor solo si aclara el objetivo. Marca como provisionales el alcance o beneficio inferidos; conserva como preguntas las elecciones especulativas de UI e implementación. Si no puedes fundamentar rol y resultado, deja la candidata pendiente. **Fin:** cada candidata se entiende en lenguaje llano y sus supuestos relevantes están visibles.
4. Ajusta el detalle al momento: una historia cercana necesita alcance suficiente para la siguiente conversación de planificación o entrega; el trabajo lejano puede seguir como objetivo amplio. Si se desconoce el horizonte, pregunta cuándo hace falta decidir. **Fin:** el detalle sirve a la siguiente decisión real, en lugar de a una hipotética.

Devuelve la candidata (o el motivo de que esté pendiente), el valor buscado y su procedencia cuando sea incierta, las restricciones relevantes conocidas y las pocas preguntas que deba responder la persona responsable. Cuando resulte útil, trata la evidencia de aceptación candidata mediante [confirmación](confirmation.md), identificándola como propuesta.

Para entregar el candidato como historia refinada o `borrador.md`, usa [Historia](../../plantillas-entregables/references/historia.md); conserva allí la procedencia y los pendientes que resulten de estos pasos.
